# Archive

One file per morning: `YYYY-MM-DD-brief.html`, exactly as it was emailed.

**Committed only after the email actually sends.** The presence of a file here
therefore means *this brief was delivered*, not *this brief was generated* —
which is the only version of that claim worth archiving.

Why this folder exists at all: `items.json` preserves what the feeds said, but
the brief is not the feeds. The grouping, the summaries and the precedent
judgements are made fresh each morning by a model and cannot be reconstructed
from the inputs. Before this folder, they existed in a sandbox for thirty
seconds and were then gone forever.
